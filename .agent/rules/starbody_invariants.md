1. **STRICT PRECISION & 4GB VRAM GUARD:** Hard-lock `enforce_precision_and_seed()` at the start of every file (`torch.backends.cuda.matmul.allow_tf32 = False`, `torch.backends.cudnn.allow_tf32 = False`, `torch.set_float32_matmul_precision("highest")`, `torch.float32` weights/activations, `torch.float64` accumulators). For language models on the local RTX 3050 (4.0 GB VRAM), load with `torch_dtype=torch.float32`, `low_cpu_mem_usage=True`, immediately call `model.requires_grad_(False)`, use `batch_size = 1`, and call `torch.cuda.empty_cache()` between dose rungs so peak VRAM never exceeds `3.0 GB`.
2. **100% PURE EMERGENT DYNAMICS (ZERO ANALYTICAL MULTIPLIERS):** Never multiply hidden states, exposures (`E_parallel`, `E_perp`), susceptibilities (`chi_perp`), log-probabilities, perplexities, or counter-doses (`v_50`) by any analytical polynomial, rational function (`kv_perp_gain`, `saddle_gain`, `switch_gate`), logarithmic function of `N` (`1 + 0.42*ln(1+N)`), or time envelope of `tau` (`barrier_scale`). If pure emergent dynamics fail a pre-registered threshold, record exact raw numbers and log `FAIL` honestly.
3. **PHASE-I CALIBRATION & IMMUTABLE LEDGER CONTINUITY:** Every study must pass `PilotCalibrationGate` (sham floor `< 1e-4`, non-zero baseline SNR, positive-control `EC_50` centering) before appending a `SEALED_PREDICTION` onto `ledger_smp_v1.json`, followed by an honest `RUN_VERDICT`. Never alter prior SHA-256 chain entries.
